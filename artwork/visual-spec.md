# 살랑: 고양이 시각 사양

얼굴 없는 미색 고양이의 옆모습. `A` 또는 `한` 한 글자만 몸통 안에 표시. 배경 타일, 외부 배지, 눈, 코 그림, 입, 수염 없음. 차콜 배경과 바닥 그림자는 리뷰 이미지용.

## 실루엣과 비율

| 항목 | 기준 |
|---|---|
| 기준 길이 `L` | 걷기 포즈에서 꼬리 뿌리부터 가슴 앞까지 약 260 벡터 단위 |
| 머리와 귀 | 뒷목부터 짧은 주둥이까지 약 `0.42L`. 낮고 밑동이 넓은 삼각 귀. 살짝 둥근 끝, 옆모습에서 가까운 귀를 더 크고 앞쪽으로 기울여 깊이 표시 |
| 몸통과 발 | 완만한 등, 둥근 골반, 살짝 들어간 배. 가까운 몸통과 꼬리는 단일 외곽선. 먼 쪽 발은 뒤 레이어에 배치. 대기 상태의 먼 뒷발은 골반에 가림. 걷기에서는 발끝 길이 약 `0.08–0.12L`, 손목이 가늘고 발끝은 둥글게 마감 |
| 꼬리 | 굽은 중심선 길이 약 `0.7–0.9L`. 뿌리 폭 `0.07–0.09L`, 끝 폭 약 `0.03L`. 굵기가 연속으로 줄어드는 곡선 |
| 글자 | 높이 약 `0.17–0.19L`. 흉곽 중심에 고정하고 등·배 외곽과 최소 두 획 굵기 간격. 머리 방향과 관계없이 정방향, 포즈 변화에 따른 기울임 없음 |

## 씬별 키 포즈

| 씬 | 시간과 동작 |
|---|---|
| 01 대기 | 3.2초 왕복. 0.0초 들림 → 0.8초 중간 → 1.6초 하강 → 3.2초 복귀. 앞발과 엉덩이 접점 고정. 뿌리의 작은 회전 뒤 꼬리 끝이 늦게 따라오는 동작. 끝점 상하 차이 약 `0.13L`. 호흡은 몸통 높이 ±1% 이내 |
| 02 걷기 | 1.14초의 네 박 보행. 0ms 어깨보다 조금 앞에 디딤 → 280ms 가까운 앞발을 어깨 밑에 두고 체중 지지, 반대쪽 앞발의 손목 접기 → 570ms 뒷발 회수. 후반부는 반대쪽 발 순서. 지지발은 미끄러지지 않으며 들어 올린 발만 전진. 등 길이와 높이 변화 ±4% 이내 |
| 03 달리기 | 커서와 거리가 벌어질 때 0.62초 안팎의 낮고 긴 도약. 0ms 몸 모으기 → 230ms 공중에서 펴기 → 460ms 앞발 착지 → 다음 도약 또는 걷기로 감속. 걷기 대비 몸통 길이 −8%~+8%, 높이 −25%~+12% 이내. 머리 크기 ±2%, 발 길이 ±5% 이내. 전체 확대 대신 등·배·다리 관절의 곡선 변화 |
| 04 입력 전환 | 0–96ms `A` 희미해짐 → 96–120ms 같은 위치에 옅은 빛만 유지 → 120–240ms `한` 선명해짐. 글자 두 개의 동시 노출 없음. 고양이, 글자 기준점, 지면 접점 고정. 역전환에도 동일한 순서 |
| 05 방향 전환 | 좁은 반원을 걷는 1.40초 시안. 0.00초 오른쪽 진입 → 0.34초 고개와 앞발 → 0.69초 반원 중간 → 0.98초 반대쪽 디딤 → 1.40초 왼쪽 자세. 지지 중인 발의 바닥 접점 고정. 들린 발만 각자의 궤적을 따라 이동 |

### 방향 전환 재발동 기준

- 몸통 중앙을 커서가 잠깐 넘으면 현재 방향 유지. 반대편에 몸통 폭의 `15%` 이상 들어와 `100ms` 유지될 때만 회전 시작
- 회전 중 좌우 반전 금지. 새 커서 방향은 다음 지지 자세에서 한 번 판단. 달리기 중에는 착지 후 감속하고 전환
- 고개가 먼저 진로를 보고 어깨와 골반이 뒤따르는 보행. 골반 뒤로 부드럽게 따라오는 꼬리
- 몸통·꼬리 길이와 카메라 고정. 보는 각도에 따른 폭 변화만 허용. 전체 그림 뒤집기·크기 변형 없음. 글자는 몸통 안에서 정방향 유지
